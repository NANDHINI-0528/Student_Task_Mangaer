
# Student Task Manager

## Project Description
Student Task Manager is a simple Python-based application that helps students manage their daily tasks and assignments.

## Features
- Add new tasks.
- View all tasks.
- Mark tasks as completed.
- Delete tasks.
- Validate user input.
- Display a simple menu.

## Technology Used
- Python

## How to Run
1. Install Python.
2. Open the project folder.
3. Run the main.py file using Python.
